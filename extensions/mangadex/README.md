# MangaDex extensions moved

The maintained source repository is now
[zwu5h/sumi-extensions](https://github.com/zwu5h/sumi-extensions).

In Sumi, add this repository URL:

    https://raw.githubusercontent.com/zwu5h/sumi-extensions/main/repository.json

Choose MangaDex Deutsch or English and install it. If you already installed the source
from the previous Sumi repository URL, remove that old repository before adding the new
one. Saved titles and reading progress remain; the source IDs are unchanged.

See the [current source documentation](https://github.com/zwu5h/sumi-extensions/blob/main/extensions/mangadex/README.md)
for maintenance commands, tests and API terms. Files retained here are a compatibility
snapshot for previously published indexes; make future adapter changes in the separate
sumi-extensions checkout.
